START HERE

1. Import this repository into Netlify.
2. Add every variable listed in .env.example to Netlify environment variables.
3. Deploy the site once.
4. Add /.netlify/functions/stripe-webhook as a Stripe webhook endpoint.
5. Copy the Stripe webhook signing secret into Netlify and redeploy.
6. Deploy the included Firestore rules and indexes.
7. Test with Stripe test mode before replacing test keys with live keys.
